# Security Policy

This repository hosts a static Jekyll site (GitHub Pages) with no backend,
database, or user-submitted data — but content and client-side code
vulnerabilities (e.g. XSS in the search UI, malicious links, supply-chain
issues in dependencies) are still in scope.

## Reporting a Vulnerability

Please report security issues privately via
[GitHub Security Advisories](../../security/advisories/new) for this
repository rather than opening a public issue. If that's not available,
open an issue with minimal detail and request a private channel.

We'll acknowledge reports within a few days and follow up with next steps.
